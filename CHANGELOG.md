# Changelog

All notable changes to Meridian are recorded here. Versions follow semver:
a token or component change that can alter how an existing app renders is a
minor bump; removing or renaming a token, class or asset is a major bump.

## [1.0.0] - 2026-10-23

### Added
- `meridian.css`: tokens (primitive + semantic, light and dark) and the `mr-` component set.
- `meridian.tokens.light.json` and `meridian.tokens.dark.json` (W3C design-token format).
- `starter.html` reference page.
- Python package `meridian` with `mount_meridian(app)` for FastAPI/Starlette apps.
